# 나만의 프롬프트 관리 프로그램

Python으로 제작한 콘솔 기반 프롬프트 관리 프로그램이다.

자주 사용하는 프롬프트를 저장하고 카테고리별로 조회하거나 검색할 수 있으며, 필요한 프롬프트를 즐겨찾기에 추가하여 관리할 수 있도록 구현했다.

## 실행 방법

### Python 버전 확인

터미널에서 다음 명령어를 실행하여 Python 버전을 확인한다.

```bash
python --version
```

Python 3.10 이상 환경에서 실행한다.

### 프로그램 실행

프로젝트 폴더에서 다음 명령어를 실행한다.

```bash
python main.py
```

프로그램이 실행되면 메뉴에 표시된 번호를 입력하여 원하는 기능을 선택한다.

## 기능 목록

### 1. 프롬프트 추가

새로운 프롬프트를 등록할 수 있다.

입력 항목은 다음과 같다.

- 제목
- 내용
- 카테고리

입력값이 비어 있는 경우 다시 입력하도록 처리했다.

### 2. 프롬프트 목록

등록된 모든 프롬프트를 번호와 함께 출력한다.

각 프롬프트의 다음 정보를 확인할 수 있다.

- 제목
- 카테고리
- 즐겨찾기 여부

즐겨찾기로 설정된 프롬프트에는 `⭐` 표시가 나타난다.

### 3. 카테고리별 조회

카테고리를 선택하면 해당 카테고리에 등록된 프롬프트만 조회할 수 있다.

해당 카테고리에 등록된 프롬프트가 없는 경우 안내 메시지를 출력한다.

### 4. 프롬프트 검색

검색어를 입력하여 프롬프트를 검색할 수 있다.

입력한 키워드가 프롬프트의 제목 또는 내용에 포함되어 있는지 확인하며, 검색 결과가 없는 경우 안내 메시지를 출력한다.

### 5. 프롬프트 상세 보기

프롬프트 번호를 입력하면 해당 프롬프트의 상세 정보를 확인할 수 있다.

- 제목
- 카테고리
- 즐겨찾기 여부
- 전체 내용

잘못된 번호를 입력한 경우 안내 메시지를 출력한다.

### 6. 즐겨찾기 관리

프롬프트 번호를 입력하여 즐겨찾기를 추가하거나 해제할 수 있다.

즐겨찾기 상태는 프로그램 실행 중에 유지된다.

### 7. 즐겨찾기 목록

즐겨찾기로 설정된 프롬프트만 모아서 확인할 수 있다.

즐겨찾기한 프롬프트가 없는 경우 안내 메시지를 출력한다.

### 0. 종료

프로그램을 종료한다.

## 등록된 카테고리

현재 프로그램에서 사용하는 카테고리는 다음과 같다.

- 이미지 생성
- 영상 생성
- 자동화
- 페르소나
- 기타

기본 데이터에는 이전 미션에서 작성한 프롬프트를 바탕으로 다음 3개의 프롬프트를 등록했다.

1. 로판 캐릭터 이미지 생성
2. SYNESTHESIA 광고 영상
3. 만족도 조사 자동화

## 코드 구조

프로그램의 기능을 여러 함수로 분리하여 구현했다.

| 함수 | 역할 |
|---|---|
| `add_prompt()` | 새로운 프롬프트 추가 |
| `show_list()` | 전체 프롬프트 목록 출력 |
| `show_category()` | 카테고리별 프롬프트 조회 |
| `search_prompt()` | 제목 및 내용 검색 |
| `show_detail()` | 프롬프트 상세 정보 출력 |
| `toggle_favorite()` | 즐겨찾기 추가 및 해제 |
| `show_favorites()` | 즐겨찾기 목록 출력 |
| `show_menu()` | 프로그램 메뉴 출력 및 기능 선택 |

프롬프트 데이터는 리스트와 딕셔너리를 사용하여 관리한다.

각 프롬프트는 다음과 같은 정보를 가진다.

- `title`: 프롬프트 제목
- `content`: 프롬프트 내용
- `category`: 프롬프트 카테고리
- `favorite`: 즐겨찾기 여부

프로그램 실행 중 새롭게 추가한 프롬프트와 즐겨찾기 상태는 프로그램이 실행되는 동안 유지되며, 프로그램을 종료하면 초기화된다.

## 개발 환경

- Python 3.10 이상
- Visual Studio Code
- Git
- GitHub

외부 라이브러리를 사용하지 않고 Python의 기본 문법을 활용하여 구현했다.

주요 사용 문법은 다음과 같다.

- 리스트(List)
- 딕셔너리(Dictionary)
- 함수(Function)
- 조건문(`if`)
- 반복문(`for`, `while`)
- 사용자 입력(`input`)
- 문자열 처리
